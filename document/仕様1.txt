言語 python
型のヒント句をつけて
fastapiで、WEBのAPIを作成

.envファイルで以下を定義
Authのdbhost(文字列)、dbport(数値)、dbname(文字列)、dbuser(文字列)、dbpass(文字列)

また、
comlibs下のauthorize.pyの中のクラスAuthorizeを使う

ファイル構成は以下で。
p52Menu/
├── main.py                    # 制御部分（FastAPIアプリの初期化とルーター登録）

├── requirements.txt           # 依存パッケージ一覧

├── routers/                   # APIエンドポイント（ルーティング）
│   ├── __init__.py

├── services/                  # 業務ロジック
│   ├── __init__.py
│   └── menu_service.py       # Menu関連の業務ロジック
├── models/                    # リクエスト/レスポンスモデル
│   ├── __init__.py
│   └── menu_models.py        # Menu関連のモデル

     ├── authorize.py          # Authorizeクラス
     └── requirements.txt

１．機能一覧要求
URL /portal/menu/api/featurelist

要求インタフェース
| No. | 項目名 | 型 | 説明 |
|:---:|--- |--- | --- |
| 1 | USER | string | 試行ユーザ名 |
| 2 | SEQ_NUMBER | number | シーケンス管理ナンバ |

処理内容
Authorizeのインスタンスを生成する。
その際の引数の値は、.envのAuthの値を使う

try_unlock_extend()を以下の引数で呼び出す。
user = 要求インタフェースのUSERの値
sequence = 要求インタフェースのSEQ_NUMBERの値

戻り値が0以上のときは正常、負数のときは異常とみなす。

正常の際は、get_feature_list()を以下の引数で呼び出す。
user = 要求インタフェースのUSERの値

以下の応答を返す。

応答インタフェース
| No. | 項目名 | 型 | 説明 |
|:---:|--- |--- | --- |
| 1 | RESULT | boolean | 結果(True/False) |
| 2 | DETAIL | string | 結果がFalseだった場合に詳細情報を設定 |
| 3 | SEQ_NUMBER | number | シーケンス管理ナンバ |
| 4 | FEATURES | list | 機能に関する情報を設定 |
| 4-1 | NAME | string | 機能名 |
| 4-2 | URL | string | URL |
| 4-3 | ICON_DATA | string | ICONデータ(BASE64) |
| 4-4 | ICON_TYPE | string | ICONデータの形式 |
| 4-5 | ORDER | number | 表示順 |

SEQ_NUMBERには、try_unlock_extend()の戻り値を設定する。
FEATURESには、get_feature_list()で取得した機能一覧を設定する。各値は以下。
FEATURES.NAME には、fname
FEATURES.URLには、feature_url
FEATURES.ICON_DATAには、icon_dataをBASE64でエンコードした値。値が無い場合は、空文字。
FEATURES.ICON_TYPEには、icon_mime_type、値が無い場合は、空文字。
FEATURES.ORDERには、1からの連番
